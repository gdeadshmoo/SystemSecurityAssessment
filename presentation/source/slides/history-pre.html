03 — History · Before computers

System security assessment

We’ve been poking at security for a long time.

1851

Alfred Hobbs picks the “unpickable” locks

Opens the Bramah and Chubb locks at the Great Exhibition, then argues that talking openly about weaknesses helps honest people more than crooks.

1883

Kerckhoffs writes down the rule

A system should stay secure even if the enemy knows everything about it except the key. Design gets judged in the open.
