02 — What this isn’t

System security assessment

AI code review: necessary, not sufficient.

Keep it in the pipeline

  • Modern LLMs are really good at finding code defects
  • Runs on every PR, at the speed code ships
  • Keeps up with AI-written code
  • Way past what old static analysis could do

What it can’t see

  • Design flaws: a broken protocol, perfectly coded
  • How components behave together
  • Deployment, config, and operations
  • Whether the requirements are even right

It’s one stage of the program, not the program.
